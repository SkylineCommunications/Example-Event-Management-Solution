# Example Event Manager

The Example Event Manager is a sample application that demonstrates what you can create using the events backend.
This backend is build using the Standard Data Model principles.

## Ad hoc data sources

Allowing to create dashboards and Low code apps to retrieve the events

## User defined API

After configuring the script "ExampleEventManager_UDAPI" with a bearer token in cube. You can retrieve the info via a webapi.

![Postman](Images/UDAPI_Postman.png)

## Example low code app

### Events page

This page allows you to upload a document and analyze it to create an event.

You can as well enter a prompt to filter out events, create a new event or edit/delete a selected event from the events table.

![Events page](Images/eventsPage.png)

### Downloads page

This page allows you to download the event example input form and also an openapi spec and postman collection

![Downloads page](Images/downloadsPage.png)
